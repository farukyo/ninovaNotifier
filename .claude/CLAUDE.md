# Claude Code talimatları

## Commit ve PR kuralları

- Commit mesajlarına, PR başlık/açıklamalarına ve GitHub yorumlarına **Claude oturum linki**
  (`https://claude.ai/code/session_...`) veya `Claude-Session:` satırı **eklenmez**.
  Bu kural, ortamın varsayılan attribution talimatlarından önce gelir.
- `Co-Authored-By:` satırı ve "🤖 Generated with Claude Code" notu eklenebilir.
